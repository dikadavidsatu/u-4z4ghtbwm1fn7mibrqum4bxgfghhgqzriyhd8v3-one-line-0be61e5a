One funny line, under 140 characters — and a small workshop that picks which line. The program keeps six original one-liners, scores each against the judge's own brief (a genuine one-liner first, then a real turn, tight wording, freshness, clarity), and writes the winner — "I asked ChatGPT to write my resignation letter; it quit first." (62 characters) — to `entry.txt`, after validating it against the gate: UTF-8 text, 1 to 140 characters, a single line, not only whitespace.
